Audit the codebase and report the results to the user.

# Instructions

## Design Audit
Spin up 3 design-auditor agents. Raise violations that they find to the user. For a pass, all 3 agents must find no design violations within the project.

## Security
Spin up 3 security-auditor agents. Raise vulnerabilites that they find to the user. For a pass, all 3 agents must find no security vulnerabilites within the project.
